# VLMux Action Protocol 1.0

VAP is the validated boundary between model adapters and action execution. Every action contains
`version: "1.0"`, a discriminating `type`, an aware timestamp, optional source/confidence
metadata, and action-specific fields.

The supported Phase 1 actions are click, double-click, right-click, move cursor, type, paste,
key, hotkey, scroll, drag, wait, screenshot, open app, focus window, close window, browser
navigate/back/forward/reload, finish, and fail.

Checked-in JSON Schema documents in `schemas/` are generated by:

```bash
python scripts/export_schemas.py
```

Raw coordinates are absolute source-screen pixels. Negative values are valid for monitors placed
left of or above the primary display. Captured regions retain their desktop origin and dimensions;
`image_to_screen_coordinates` and `screen_to_image_coordinates` perform the canonical mapping.
`validate_action_coordinates` checks absolute points against the captured native region before
policy evaluation or execution.
